## 前言

最近在練習如何寫微服務時，利用 gRPC 來達成服務間的溝通，正當新增完 ASP.NET grpc 服務專案後，還沒開始任何操作，竟然報錯了！

錯誤訊息：

```text
protoc-gen-grpc: The filename, directory name, or volume label syntax is incorrect
```

（原文有附錯誤截圖，可參考原文連結）

一開始有想到，應該是路徑有中文或其他特殊字元等等的問題，就將專案路徑改成英文，但事情沒那麼簡單！還是報一樣錯！

## 為什麼呢？

因為在建立類似 grpc 服務的模板專案時，除了自己設定的專案路徑以外，還有其他 library 的相關設定檔可能在其他地方，而路徑中就可能包含中文或特殊字元，才會導致就算把專案路徑改成英文，也還是會報錯的情況！

依照自身的情況，路徑有中文或特殊字元，就立馬想到了我 Windows 的 user name 是中文，才導致錯誤發生！

## 提供以下兩個解決方法

1. 再創一個 Windows user，切記 user name 不能有中文或特殊字元！
2. 變更 Windows user name。（單純修改名稱是沒有效果的喔！請參考「如何變更 Windows user name」的教學影片）
