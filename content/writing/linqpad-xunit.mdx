## 前言

最近我們正在把公司的舊專案升級至 .NET 6，升級的過程中不可避免地需要進行重構。為了輔助驗證，需要進行測試。

而在 LINQPad 上寫測試，可以減少開專案和檔案的時間，加快驗證重構的想法，耶～

以下將會介紹如何在 LINQPad 安裝 xUnit～

版本：LINQPad 7

## 在 LINQPad 上安裝 xUnit

點選上方列的 `Query` / `Add XUnit Test Support`，會自動安裝 xUnit 所需的工具。

安裝結束後，會提供樣板程式。

每次開新的 Query，只要再次點選 `Query` / `Add XUnit Test Support`，LINQPad 就會幫你產生樣板 Code 囉！是不是很棒很方便呢！
